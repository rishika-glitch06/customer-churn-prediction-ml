# 📊 Customer Churn Prediction using Machine Learning

## 📌 About the Project
This project focuses on predicting whether a customer is likely to leave a service (churn) based on their usage patterns and account details.

It helped me understand how machine learning can be applied to solve real-world business problems like customer retention.

---

## ⚙️ Tech Stack
- Python  
- Pandas & NumPy  
- Scikit-learn  
- Matplotlib  

---

## 🧠 Model Used
- Logistic Regression (Classification Model)

---

## 📊 Results
- Achieved ~0.79 Accuracy
- Evaluated model using Confusion Matrix & Classification Report
